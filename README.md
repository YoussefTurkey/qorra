# موقع قراء الرسمي التعريفي
قُرَّاءْ هى مبادرة مختلفة من حيث الشكل عن أي مبادرة أخرى؛ لأن لها فرعان رئيسيان.
#### لجان المبادرة:
- لجنة التطوير
- لجنة التقييم
- لجنة الإعلام
- لجنة العلاقات العامة والتنظيم
- لجنة إدارة المشروعات
#### أجنحة المبادرة
- جناح صون اللسان
- جناح صناعة قارئ
- جناح الجريدة
- جناح البحث العلمي
- جناح الخدمة المدنية


### اللغات المستخدمة
* HTML5
* Scss
* JS
* jQuery
* React.js as framework
* React-Bootstrap
* Boxicons
* Swiper.js
* Router-dom
* Form-stepper

#### Should to install before start
* to implement SCSS 
    - ' >> npm install -g sass '
    - ' >> npm i sass --save-dev '
* to implement React-Bootstrap
    - ' >> npm install react-bootstrap bootstrap '
* to implement Boxicons
    - ' >> npm install boxicons --save '
* to implement jQuery
    - ' >> npm install jquery --save '
* to implement Swiper.js
    - ' >> npm i swiper '
* to implement Router-dom
    - ' >> npm install react-router-dom@5.2.0 '
* to implement Form-stepper
    - ' >> npm i react-form-stepper '
    - ' >> npm install react-form-stepper --save '
