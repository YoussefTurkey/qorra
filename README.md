# موقع قراء الرسمي التعريفي
قُرَّاءْ هى مبادرة مختلفة من حيث الشكل عن أي مبادرة أخرى؛ لأن لها فرعان رئيسيان.
#### لجان المبادرة:
- لجنة التقييم والتطوير
- لجنة الإعلام
- لجنة العلاقات العامة والتنظيم
- لجنة إدارة المشروعات
#### أجنحة المبادرة
- جناح صون اللسان
- جناح صناعة قارئ
- جناح الجريدة
- جناح البحث العلمي
- جناح الخدمة المدنية


### اللغات المستخدمة
* HTML5
* Scss
* JS & JSX
* jQuery
* Next.js as framework v13
* React-Icons
* Swiper.js

#### Should to install before start
* to implement SCSS 
    - ' >> npm install -g sass '
    - ' >> npm i sass --save-dev '
* to implement React-Icons
    - ' >> npm install react-icons --save '
* to implement jQuery
    - ' >> npm install jquery --save '
* to implement Swiper.js
    - ' >> npm i swiper '
